# 주석 기준서 수정본

수정일은 2026년 11월 22일이다. 초기 기준서에 모델 예측과 제공 라벨을 대조한 검토 결과를 반영하였다. 보이는 결함 영역을 폴리곤으로 표시하고 한 영상에서 확인되는 결함은 클래스별로 각각 주석한다. PDF 보고서 마지막 페이지에 같은 기준을 한 페이지로 정리하였다.

## 1. 클래스 정의와 포함·제외 기준

| ID / 클래스 | 정의와 포함 기준 | 제외 대상 | 경계 규칙 |
|---|---|---|---|
| 0 / crack | 콘크리트 표면이 갈라져 생긴 틈. 갈라진 경로와 폭이 식별되는 부분을 포함한다. | 시공 이음부, 케이블·배관, 그림자, 단순 표면 질감 | 보이는 폭을 따라 양쪽 경계를 잇고 가려진 구간은 끊어 표시한다. |
| 1 / efflorescence | 콘크리트 표면에 생긴 흰 침착물. 침착 질감과 가장자리가 식별되는 범위를 포함한다. | 빛 반사, 먼지·변색, 보수 재료의 색 차이 | 확인되는 침착물까지 표시한다. 밝기 변화만 있는 주변 표면으로 확장하지 않는다. |
| 2 / spall_detach | 표면층이 분리되거나 떨어져 나간 상태. 패인 면, 탈락 경계, 노출된 내부가 보이는 영역을 포함한다. | 고정 구멍, 보수 재료, 얼룩과 백태만 있는 영역 | 재료 손실 경계를 따르고 주변의 온전한 면까지 넓게 둘러싸지 않는다. |

## 2. 판단 보류

사진만으로 침착물·오염·보수 흔적을 구별하기 어렵거나 실제 틈과 재료 손실을 확인하기 어려우면 파일명, 위치, 보류 이유를 기록한다. 원본과 주변 영상, 제공 라벨을 대조한다. 미주석 영상은 확인된 배경과 구분해 관리한다.

## 3. 오류 분석을 반영한 보완

- 균열은 어두운 선이라는 이유만으로 주석하지 않는다. 이음부의 일정한 폭과 표면이 갈라진 틈을 함께 살핀다.
- 백태는 밝기만으로 결정하지 않고 침착 질감과 경계를 확인한다. 밝게 비친 콘크리트 표면을 넓게 포함하지 않는다.
- 박리·박락은 흰 침착물이나 거친 질감만으로 부여하지 않는다. 실제 표면 손실과 분리 경계를 확인한다.
- 제공 라벨 기준 FP라도 사진에 실제 결함이 있을 가능성은 검토한다. 정답 수정은 별도 검토와 버전 기록을 거쳐 수행한다. 이번 평가의 정답 라벨은 제공 파일을 사용하였다.

## 4. 저장과 검수

클래스 ID와 0~1 정규화 좌표로 저장한다. 다각형은 최소 3개 꼭짓점으로 닫고 저장 후 겹침·누락·좌표 범위를 확인한다. 예시 영상은 [최종 보고서](project_report.pdf)의 주석 기준서 페이지와 [오류 분석](error_analysis.md)에 수록하였다.
